\# Git Version Control Experiment



\## Objective



To use Git for version control in an open-source project and understand basic repository management and collaboration workflows.



\## Experiment Details



This experiment demonstrates:



\- Git repository initialization

\- File tracking

\- Staging and committing changes

\- Branch creation

\- Branch switching

\- Branch merging

\- Remote repository configuration

\- Pushing changes to GitHub



\## Git Workflow



The project uses Git branches to develop features independently before merging them into the main branch.
